Política de Privacidade do Jarvis

O Jarvis é um aplicativo pessoal, de uso exclusivo do seu próprio dono, que roda no computador dele.

Quais dados o aplicativo acessa

Somente depois que o dono entra com a própria conta Google e concede a permissão, o aplicativo pode acessar dados dessa conta (como agenda, e-mails e arquivos do Drive) para executar pedidos feitos pelo próprio dono.

Como os dados são usados e guardados

  • Os dados são lidos e processados no computador do dono, apenas para atender aos pedidos dele.
  • Os dados do Google não são vendidos, não são compartilhados com terceiros e não são usados para publicidade.
  • Trechos de texto podem ser enviados a serviços de inteligência artificial escolhidos pelo dono, apenas para gerar a resposta a um pedido dele, e não para treinar modelos de uso geral.
  • O dono pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Uso de dados de APIs do Google

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
